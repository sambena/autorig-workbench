Models to try the tool on go here, one folder each (`samples/<model>/<export>.fbx` with its textures in
`<export>.fbm/`, or a `.glb`, `.gltf` or `.obj`), each with its `rig.json` (docs/SPEC.md). This is the default models
root (`AUTORIG_MODELS`). Only this note and the bundled samples (beetle, biped, canine, pedestal, wyvern: generated, CC0) are committed;
models you add here are ignored by git.
